Política de privacidad de ShortsIA

Última actualización: 16 de septiembre de 2026

Qué es ShortsIA

ShortsIA es una herramienta interna que usa los Servicios de API de YouTube para subir vídeos al canal de YouTube de su propietario (Alejandro Navarro). No la usan terceros.

Datos a los que accede

La aplicación solicita únicamente el permiso youtube.upload, que se usa exclusivamente para subir vídeos, con su título, descripción y etiquetas, al canal del propietario. No lee, almacena ni comparte datos personales, comentarios, suscriptores ni otra información de cuentas de YouTube o Google.

Almacenamiento y seguridad

El token de autorización se guarda cifrado como secreto en un repositorio privado de GitHub y solo se usa para realizar las subidas. No se venden ni se ceden datos a terceros.

Servicios de terceros

Al usar esta aplicación se aplican los Términos del Servicio de YouTube y la Política de Privacidad de Google.

Revocar el acceso

El acceso se puede revocar en cualquier momento desde la configuración de seguridad de la cuenta de Google.
